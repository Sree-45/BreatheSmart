================================================================================
1. ELEVATOR PITCH
================================================================================

BreatheSmart is a full-stack air-quality + health-intelligence platform.

What the user sees:
  - A live AQI map (Google Air Quality + Maps).
  - A health-conscious profile (conditions, vitals, blood type, uploaded
    medical reports).
  - Personalized "Take action now / Also worth doing" recommendations whose
    sources (WHO, EPA, AHA, NHLBI, plus the user's own uploaded reports) are
    visible and clickable.
  - An optional "agentic analysis" panel where a LangGraph agent autonomously
    fetches AQI, runs RAG, and explains its tool trace.
  - A daily two-sentence digest banner generated by Spring AI ChatClient.

What's behind the scenes (three runtime services):
  1. frontend/      — React 19 + Vite (HTTPS dev server :5173)
  2. backend/       — Spring Boot 3.5 + MongoDB + JWT + Spring AI (:8080)
  3. rag-service/   — FastAPI + LangChain + LangGraph + Gemini + ChromaDB (:8000)

Plus stateful infrastructure: MongoDB (users, reports metadata) and ChromaDB
(global guideline corpus + per-user report chunks).

================ README.md ================
# BreatheSmart

Full-stack air-quality and health-intelligence platform. Live AQI on a map,
RAG-grounded health recommendations with source citations, and a LangGraph
agent that picks its own tools.

Three runtime services:
- frontend     React 19 + Vite (HTTPS dev)
- backend      Spring Boot 3.5 + MongoDB + JWT + Spring AI
- rag-service  FastAPI + LangChain + LangGraph + Gemini + ChromaDB

[Sections covered: Architecture, Quick start (Docker Compose), Manual setup
(no Docker), Populating the RAG data folder, AI evaluation (RAGAS),
Structured logging, Resilience and security, Project structure,
Troubleshooting.]

Key commands:
  cp .env.example .env
  docker compose up --build
  curl -X POST http://localhost:8000/ingest/global
  cd frontend && npm install && npm run dev   # https://localhost:5173

Required env vars:
  GEMINI_API_KEY            (required) — Google AI Studio key
  JWT_SECRET                (required) — `openssl rand -hex 64`
  GOOGLE_MAPS_API_KEY       (optional) — for live AQI / Maps
  MONGODB_URI               (optional) — defaults to local docker mongo
  GEMINI_MODEL              (optional) — defaults to gemini-2.5-pro

Recommended PDFs to drop into rag-service/data/pdfs/ (gitignored):
  - WHO Global Air Quality Guidelines 2021 (executive summary)
  - US EPA AQI Technical Assistance Document
  - EPA Particulate Matter Health Effects
  - NHLBI Asthma Action Plan
  - GOLD COPD Pocket Guide
  - AHA Air Pollution and Cardiovascular Disease
  - ACOG / RCOG environmental health committee opinions

Naming convention: <source>_<topic>.pdf — that filename surfaces under
sources[].source in the /recommend response.

ReportUploadController  /api/users (authenticated, multipart)
  - POST   /{userId}/reports             multipart "file"
        flow:
          1. Auth check + user-id match (403 if mismatch).
          2. FileStorageService.store → user-scoped dir under app.uploads.dir.
          3. Tika.parseToString (max 10MB extracted text).
          4. POST text to rag-service /ingest/report (RagServiceClient).
             - 400 from Python (non-medical doc) → bubbled as 400 with helpful
               copy and the file is deleted from disk.
             - Other RAG failures → 503 + delete file.
          5. On success, append Report to user.pastReports and save.
  - GET    /{userId}/reports             returns user.pastReports

6.4 RAG core (app/rag/)
------------------------------------------------------------

llm.py
  get_llm() = ChatGoogleGenerativeAI(model=gemini_model, temperature=0.3,
              timeout=llm_timeout_s, max_retries=llm_max_retries).
  Raises RuntimeError if GEMINI_API_KEY missing.

retriever.py
  retrieve(query, user_id?, k?)
    scopes = ["global"] + (["user_<id>"] if user_id else [])
    where = {"scope": {"$in": scopes}}
    returns vs.similarity_search_with_score(query, k=k, filter=where)
  has_relevant_results(results) — True if any score < settings.similarity_threshold.

prompt.py
  RAG_PROMPT (LangChain PromptTemplate). Slots:
    advisory, context, age, conditions, blood_type, height, weight,
    aqi, category, dominant_pollutant, city, question
  Reply schema enforced as JSON {primary[≤4], secondary[≤4]}.
  ADVISORY_RAG vs ADVISORY_FALLBACK chosen by has_relevant_results().

pipeline.py
  run_recommendation(user_profile, aqi_data, question?) →
    {recommendation, sources, fallback, latency_ms, request_id}
  Steps:
    1. _build_query(user_profile, aqi_data, question) — natural-language
       form of the retrieval query.
    2. retrieve(...) with retriever_k=4.
    3. _format_context(results) — "[Source: <name>] <chunk>" sections.
    4. RAG_PROMPT.format(...).
    5. llm.invoke(prompt).
    6. _strip_json_fence + json.loads + _coerce_recommendation
       (forces lists, truncates each list to 4 items).
    7. On JSON parse error → keep raw text as primary[0], log
       json_parse_failed.
    8. On LLM error → log, fall back to _FALLBACK_RECOMMENDATION
       (deterministic safety advice). fallback flag set True.
    9. Build sources[]: {source, scope, snippet[:240], score=float(L2)}.
    10. Emit ONE rag.events JSON log line with: request_id, user_id, query,
        k, retrieved[*].score, min_score, fallback_grounding, llm_failed,
        json_parse_failed, retrieve_latency_ms, llm_latency_ms,
        total_latency_ms.

6.6 LangGraph agent (app/agent/)
------------------------------------------------------------

tools.py
  fetch_aqi_for_city(city) → {aqi, category, dominant_pollutant, city,
                              source: "google_air_quality"|"mock", note?}
    - Uses GOOGLE_MAPS_API_KEY + hard-coded geocoding for Hyderabad,
      Delhi, Mumbai, Bengaluru, Chennai, Kolkata.
    - Mock fallback returns AQI=156 (Unhealthy, PM2.5).
  get_health_recommendation(age, medical_conditions, aqi, category,
                            dominant_pollutant, city, question="")
    - Calls run_recommendation(...) directly (full RAG pipeline).
  ALL_TOOLS = [fetch_aqi_for_city, get_health_recommendation]

graph.py
  AgentState  TypedDict { messages: List[BaseMessage] (add_messages reducer) }
  SYSTEM_PROMPT enforces tool-use policy:
    1. If user mentions a city but no AQI → MUST call fetch_aqi_for_city.
    2. Then MUST call get_health_recommendation with age, conditions, AQI.
    3. Never invent AQI / citations.
    4. After tools, summarize in 2-4 sentences with AQI value, dominant
       pollutant, and the single most important action.
    5. Do not call any tool more than twice. Do not loop.
  build_graph() (lru_cache(1)):
    - LLM = ChatGoogleGenerativeAI(temp=0.2).bind_tools(ALL_TOOLS)
    - Nodes: agent (call_model, prepends SystemMessage if absent),
             tools (ToolNode(ALL_TOOLS))
    - Conditional edge from agent: if last message has tool_calls → tools,
      else END. Edge tools → agent.

8. KEY CONTRACTS (cross-service)
================================================================================

POST /recommend  (backend↔rag-service)
  REQUEST  { user_profile: { user_id, age, medical_conditions,
                             blood_type, height, weight },
             aqi_data: { aqi, category, dominant_pollutant, city },
             question? }
  RESPONSE { recommendation: { primary[], secondary[] },
             sources: [{source, scope, snippet, score}],
             fallback: bool, latency_ms, request_id }

POST /agent/analyze
  REQUEST  { city, age?, medical_conditions?, question? }
  RESPONSE { answer, trace: [{type, content, tool_calls}] }

POST /ingest/report
  REQUEST  { user_id, report_text, filename }
  RESPONSE { chunks, user_id, filename, skipped? }

JWT:
  Algorithm: HS-keyed. Secret = jwt.secret env. Subject = phone.
  Expiration = 24h (jwt.expiration=86400000).
  Frontend stores both `authToken` and `user` in localStorage; clears both
  on 401/403 to prevent the corrupted-session bug.

ChromaDB scope filter:
  Always include scope ∈ {"global"} ∪ ({"user_<id>"} if user_id else ∅).
  L2 distance (lower = more similar). Threshold default 1.2.

9. RESILIENCE & SECURITY DECISIONS WORTH PRESERVING
================================================================================

- LLM calls have timeout + retry; on failure, run_recommendation returns
  _FALLBACK_RECOMMENDATION (deterministic safety advice) and sets
  fallback=True. AiSummaryService falls back to a templated digest.
- LangGraph agent has recursion_limit=8 and a tool-use policy in the
  system prompt that caps repeated tool calls.
- Spring controllers pin CORS to dev origins where it matters (no `*`
  on AI/auth endpoints). MapController + AirQualityController use `*`
  because the data is public.
- /api/auth/**, /api/map/**, /api/air-quality/** are public.
  /api/ai/**, /api/users/** require JWT.
- Frontend axios interceptor wipes BOTH authToken and user on 401/403.
- ReportUploadController guards user-id mismatch (403) and deletes the
  file from disk if rag-service indexing fails.
- FileStorageService sanitizes user-supplied filenames and asserts the
  resolved user dir stays under baseDir (path traversal guard).
- ingest/report rejects non-medical documents (Gemini YES/NO check) and
  truncates to MAX_REPORT_CHARS=200_000.
- pipeline.py emits a single structured `rag.events` JSON log per
  /recommend call, including request_id for cross-service correlation.

10. KNOWN GOTCHAS / ROUGH EDGES (good for an LLM to remember)
================================================================================

- Spring uses NoOpPasswordEncoder (passwords stored in plaintext). For any
  real deployment, swap to BCryptPasswordEncoder.
- MapController.reverseGeocode is currently a placeholder that returns
  "Location (lat, lng)"; the real reverse-geocoding is done client-side
  via Google's Geocoder.
- AiController.AirQualityController + MapController use CORS `*`.
- Forecast endpoint uses pageSize=24 and a fixed +24h window; Google may
  return fewer hours for some regions — frontend handles empty arrays.
- frontend Home.jsx initial geolocation: Wi-Fi-only laptops can show
  multi-km accuracy; the cutoff was raised to 25km soft / hard.
- rag-service/data ships markdown only. Real PDFs (WHO/EPA/AHA/etc.) must
  be dropped into rag-service/data/pdfs/ (gitignored) and re-ingested.
- Re-ingestion: stop rag-service, delete rag-service/chroma_db/ (or
  `docker volume rm breathesmart_chroma_data`), re-run /ingest/global.
- The ingest/report Gemini "is this a medical document?" check is a hard
  YES/NO classifier; on Gemini failure it falls back to True (i.e. allow
  ingestion) so users aren't locked out by upstream outages.

  cp .env.example .env                # set GEMINI_API_KEY + JWT_SECRET
  docker compose up --build
  curl -X POST http://localhost:8000/ingest/global
  cd frontend
  npm install
  echo 'VITE_GOOGLE_MAPS_API_KEY=...' > .env.local

  # rag-service
  cd rag-service && python -m venv venv && source venv/bin/activate
  pip install -r requirements.txt
  cp .env.example .env                # set GEMINI_API_KEY
  python main.py                      # :8000
  # backend
  cd backend && export GEMINI_API_KEY=... JWT_SECRET=... GOOGLE_MAPS_API_KEY=...
  ./mvnw spring-boot:run              # :8080
  # frontend (as above)

  http://localhost:8000/health
  http://localhost:8080/actuator/health

  cd rag-service && python scripts/eval_ragas.py
  python scripts/eval_ragas.py --json out.json
  python scripts/eval_ragas.py --no-ragas       # keyword fallback
